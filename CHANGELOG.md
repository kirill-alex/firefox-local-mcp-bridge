# Changelog

## 0.1.0 — initial public-source preparation

- Local authenticated stdio MCP bridge and Firefox WebExtension.
- Separate WebDriver BiDi backend for native page input and diagnostics.
- Verified scroll results, explicit hidden-page DOM fallback and bounded activation wait.
- Experimental, read-only SyncShare DOM inspection restricted to a configured Moodle site.
- Per-install generated token and extension settings page; secrets are not embedded in extension packages.
- Sanitized source packaging, tests, public-file check and Windows/Linux CI definition.

Known limitations are listed in README.md and docs/. No Mozilla signature or public store listing is included.
